## **Backend Guidelines**

### Regras de Código para Backend

1. **Sempre usar Framework:**
   Nada de reinventar o backend do zero. Use Laravel, CodeIgniter, Express ou outro framework para manter tudo organizado.

2. **Validação Antes do Banco:**
   Valide todos os dados antes de salvar. Evita dor de cabeça e erros bizarros.

3. **Validador do Framework:**
   O framework provavelmente já tem validação pronta. Use e aproveite!

4. **Segurança dos Dados:**
   Dados maliciosos não entram. Filtre, verifique e garanta que o banco fique seguro.

5. **Evitar Redundância:**
   Reaproveite funções, middlewares e classes. Menos repetição, mais elegância.

6. **Nomes em Inglês:**
   Variáveis, funções, tabelas e endpoints devem ser em inglês. Facilita a vida de todo mundo.

7. **Valores Repetitivos:**
   Credenciais, endpoints e valores repetitivos? Armazene em variáveis de ambiente ou no topo do código.

8. **Documentação:**
   Use DocBlocks e comentários para deixar claro o que cada função faz.

9. **Código Limpo e Legível:**
   Indentação organizada, nomes claros e comentários ajudam a não se perder.

10. **Commits Claros:**
    Mensagens de commit devem explicar bem o que foi feito. “Arrumei umas coisas” não conta. 😅
